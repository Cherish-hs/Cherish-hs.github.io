欢迎来到我的个人博客！🎉

这个博客使用 **Jekyll** 搭建，部署在 **GitHub Pages** 上，整个过程完全免费。
写下这篇文章，记录博客诞生的第一天。

<!--more-->

## 为什么写博客

学习过程中，我发现**输出是最好的输入**：

1. 写下来能倒逼自己把知识真正理解清楚；
2. 踩过的坑记录下来，下次遇到可以直接查；
3. 也许能帮到遇到同样问题的同学。

## 博客会写些什么

- ROS 机器人学习笔记
- Python 编程练习与进阶知识点
- 计算机视觉（OpenCV / YOLO）实践
- 项目开发过程中的经验总结

## 技术栈

| 项目 | 说明 |
| --- | --- |
| 静态站点生成 | Jekyll |
| 托管 | GitHub Pages |
| 自动部署 | GitHub Actions（jekyll-build-pages） |
| 文章格式 | Markdown |
